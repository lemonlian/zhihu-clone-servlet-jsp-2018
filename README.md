# onlinezhihu · 手写一个知乎（Servlet + JSP）

> 2026-11-15 补写说明：这是 9 个老仓库里**功能最完整、最像成品**的一个。

## 这是什么
2018 年 3 月用原生 Servlet + JSP + JDBC 手写的一个问答社区，模仿知乎的核心功能，没有用任何框架。

## 功能范围（从 Servlet 分类看）
| 模块 | 做了什么 |
|---|---|
| 用户 user | 登录、查看/修改个人资料 |
| 话题 topic | 发布、删除、修改、按 ID 查、详情页、搜索、收藏、首页新帖列表 |
| 板块 board | 新增、删除、修改、详情 |
| 回复 reply | 发表、删除、修改、按 ID 查详情 |

## 技术栈
JSP + Servlet + JDBC + MySQL + HTML/CSS/jQuery，纯手写，无 Spring、无 MyBatis。

## 现状
- 最后提交 2018-03-10，226 个文件。
- 需要 Tomcat + MySQL 才能跑，当年是这么部署的；今天要跑得自己配数据源。
- 仓库里同样混了 `out/` 编译产物和 `.idea/`。

## 为什么值得留
这是理解「框架帮你做了什么」的最好对照物——手写过一遍 Servlet 分发、参数解析、连接管理，再看 Spring 就明白它在省什么。
